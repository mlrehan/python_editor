# Python Cloud Studio — Verified Feature Inventory & Documentation Matrix

This inventory records the verified UI locations, behaviors, and testing status of features in the **Python Cloud Studio** application (`http://localhost:8765`), used as the technical truth source for the official User Guide.

| # | Feature | Actual UI Location | Actual Behavior & Workflows | Verification Status |
|---|---|---|---|---|
| 1 | **Guest Mode (Private Workspace)** | Top Navbar badge (`Guest Mode — Private Workspace`) + banner + left sidebar `Guest` badge | Zero-login access. Each browser gets a server-signed guest token and its own folder (`storage/workspaces/guests/<id>/`), notebooks and kernel; other guests cannot see or change it. A copy is kept in the browser (IndexedDB) and restored if the server removed the workspace (unused for `GUEST_WORKSPACE_IDLE_DAYS`). `storage/workspaces/public/` holds the starter files copied into new guest workspaces. | **Implemented & Verified** |
| 2 | **Authentication (Login & Register)** | Top Navbar right corner (`Sign In` button) | Non-blocking modal dialog. Supports registration (Email, Password, Name, Role) and login. Upon login, seamlessly switches to private tenant workspace without page reload. | **Implemented & Verified** |
| 3 | **Private Workspace Isolation** | Top Navbar badge (`Signed In — Private Workspace`) + left sidebar `[Private]` / `[Admin]` badge | Files stored in `storage/workspaces/user_{user_id}/default/`. Cross-tenant traversal (`../user_`) strictly blocked at API, static regex analyzer, and `sitecustomize.py` runtime hook. | **Implemented & Verified** |
| 4 | **Logout Lifecycle** | Top Navbar user section (`Sign out` red button) | Clears JWT token, resets active notebook ID, closes all right-sidebar preview tabs, unmounts private sidebar, remounts public workspace. | **Implemented & Verified** |
| 5 | **Notebook Creation & Selection** | Top Navbar `Notebooks` button (`<BookOpen>`) & `+ File` in Left Sidebar | Creates Jupyter v4 `.ipynb` files. `NotebooksModal` lists notebooks, creates new, switches active, downloads `.ipynb`, duplicates, and deletes. | **Implemented & Verified** |
| 6 | **Code Cell Execution** | Code cell left gutter `<Play>` button & Top Navbar `Run All` | Dispatches execution via ZeroMQ to IPyKernel. Real-time streaming output via WebSockets (with REST fallback). Gutter shows spinner during execution and updates execution counter `[1]`. | **Implemented & Verified** |
| 7 | **Keyboard Shortcuts** | Notebook, code cells, file editor; full list via toolbar `Shortcuts` dialog | `Ctrl+Enter` (run, keep focus), `Shift+Enter` (run & advance), `Alt+Enter` (run & insert below), `Ctrl+C` (stop running code when nothing is selected), `Ctrl+/` (toggle comments), `Tab`/`Shift+Tab` (indent/outdent lines), `Ctrl+Space` (suggestions & function help), `Ctrl+S` (save notebook, or the open file while editing it), `Ctrl+B` (toggle Files sidebar), `Esc` (close popups/dialogs). macOS uses `⌘` (`⌃` for `Ctrl+C` and `Ctrl+Space`). | **Implemented & Verified** |
| 8 | **Kernel Restart Lifecycle** | Top Navbar `Restart` button (`<RotateCcw>`) | Re-initializes IPyKernel process, clears ZeroMQ channels. Navbar button spins (`animate-spin`), disables during restart, shows toast notifications, and pulses blue status badge. | **Implemented & Verified** |
| 9 | **Kernel Status Monitoring** | Top Navbar status pill (`Python 3 (idle)`) | Live indicator: Green (`idle`), Amber (`busy`), Pulsing Blue (`restarting`), Red (`disconnected`). | **Implemented & Verified** |
| 10 | **Python IntelliSense Autocomplete** | Code cell editor (custom textarea editor) | Popup below the cursor, flipping above when space is short. Shows functions/attributes. ArrowUp/Down scrolls list; Tab/Enter inserts token. Escape dismisses. Signature help box is scrollable, selectable and copyable, and stays inside the visible notebook area. | **Implemented & Verified** |
| 11 | **Parameter Signature Help** | Code cell editor upon typing `(` | Displays parameter names, defaults, and docstrings. Positioned intelligently so it never collides with or overlaps autocomplete dropdown. | **Implemented & Verified** |
| 12 | **Real-Time Code Diagnostics** | Code cell editor text overlay | Red squiggly underline on syntax errors and unresolved imports with hover tooltip. Suppresses errors during active typing; auto-refreshes on cell run and kernel restart. | **Implemented & Verified** |
| 13 | **Interactive Data Table (`DataTableView`)** | Cell output below Pandas DataFrames | Automatically upgrades pandas HTML tables (`table.dataframe`) into an interactive viewer with column sorting, live search filter, pagination, CSV download, and TSV copy. | **Implemented & Verified** |
| 14 | **Vertical Cell Resizing** | Drag handle at bottom of code cell | Smooth vertical dragging (80px to 800px). Metadata `custom_height` persisted across sessions. Double-click resets to auto-fit. | **Implemented & Verified** |
| 15 | **Package Installation (`%pip install`)** | Code cell statement | Automatically appends `--user` into user's `.local/site-packages`. Post-execution hook immediately discovers packages without requiring manual kernel restart. Guest/unprivileged blocked. | **Implemented & Verified** |
| 16 | **File Explorer & CRUD** | Left Sidebar (`FILES`) | Tree view of files/folders. Action buttons: `+ File`, `+ Folder`, `Upload`, `Refresh`. Drag-and-drop upload. Right-click context menu: Rename, Download, Delete. | **Implemented & Verified** |
| 17 | **Tabbed File Editor** | Right Sidebar panel | Double-clicking `.py`, `.csv`, `.md`, `.txt` in file explorer opens a tab. Dirty bullet `●`, Save button, Close `(X)` with unsaved confirmation dialog ("Save and Close", "Discard", "Cancel"). | **Implemented & Verified** |
| 18 | **AI Coding Assistant** | Right panel (`AI Assistant` tab) | Chat interface for Python programming questions, Pandas/NumPy snippet generation, and error explanations. Includes "Insert in Notebook" button. | **Implemented & Verified** |
| 19 | **Kernel Variables & Metrics** | Right panel (`Variables` & `Metrics` tabs) | Variables tab displays active kernel memory scope; Metrics tab displays CPU (2.0 Cores), RAM (4.0 GB), and Disk (10.0 GB) allocations. | **Implemented & Verified** |
| 20 | **Workspace Secrets & API Keys** | Top Navbar `Secrets` button (`<Key>`) | `SecretsModal` provides preset templates (`OPENAI_API_KEY`, `GEMINI_API_KEY`, `ANTHROPIC_API_KEY`, `HUGGINGFACE_API_KEY`) and custom keys. Stored in workspace `.env` and injected into kernel. | **Implemented & Verified** |
| 21 | **Theme Switching** | Top Navbar theme button | Dropdown to switch between `System` (syncs with OS dark/light), `Dark`, and `Light`. Fully driven by semantic CSS custom properties in `index.css`. | **Implemented & Verified** |
| 22 | **SuperAdmin Console** | Top Navbar `Admin` button (amber shield) | Available for `super_admin`/`admin`. Tabs: System Overview, Users, Packages (system-wide install/uninstall), Runtimes (clear kernels), Workspaces (inspect tenant files), Audit Logs, Settings. | **Implemented & Verified** |
| 23 | **Python Debugging Workflow** | Code cells & exception outputs | Interactive debugging is performed via Python standard `breakpoint()`, `pdb`, try/except blocks, and ANSI tracebacks. Dedicated visual DAP stepping GUI is planned for future releases. | **Documented (Current vs Roadmap)** |
| 24 | **Terminal & Shell Access** | Code cells (`!` bang commands & `%` magics) | Shell commands execute safely through IPython code cells with security filters blocking destructive host commands. Dedicated web PTY xterm shell is planned for future release. | **Documented (Current vs Roadmap)** |
| 25 | **Classroom & Assignment System** | Backend REST API (`/api/v1/classrooms`) | Instructors create classrooms, generate join codes, post assignments, and grade student submissions. Backend ready for institutional LMS integrations. | **Documented (API & Enterprise Scope)** |
